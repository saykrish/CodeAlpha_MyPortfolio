## 🌐 Deployment Options

### Deploy to Netlify (1-Click Drag & Drop)
1. Go to [Netlify.com](https://www.netlify.com/) and sign in.
2. Go to **Sites** → **Add new site** → **Deploy manually**.
3. Drag and drop the `Codealpha.MyPortfolio` folder into the Netlify upload box.
4. Your site will be instantly live with a global HTTPS URL!

### Deploy to GitHub Pages (Free)
1. Initialize git in the project root:
   ```bash
   git init
   git add .
   git commit -m "feat: updated dileep.dev portfolio with live projects and saykrish github"
   ```
2. Create a repository on GitHub (under `saykrish`), link it, and push:
   ```bash
   git remote add origin https://github.com/saykrish/dileep-portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. In GitHub repository **Settings** → **Pages**, select `main` branch and `/ (root)`.
